# 会員情報管理画面の仕様

## 概要

会員情報の登録・閲覧・編集・削除を行う管理画面です。管理者権限を持つアカウントでログインした場合に表示します。

## 一覧画面

1. ログイン後、メニューの「会員管理」を押すと一覧画面を表示します。
2. 一覧は登録日の新しい順に20件ずつ表示し、21件目以降はページ送りで表示します。
3. 検索欄に会員名か会員番号を入力して検索ボタンを押すと、部分一致した会員だけを表示します。
4. 該当する会員がいない場合は「該当する会員はいません」と表示します。
5. 各行の「編集」を押すと編集画面を、「削除」を押すと確認ダイアログを表示します。
6. CSV出力ボタンを押すと、検索条件に一致した会員をすべてCSVで出力します。

## 新規登録画面

1. 一覧画面の「新規登録」を押すと、空の入力欄を表示した状態で新規登録画面を開きます。
2. 会員名は必須で、50文字まで入力できます。
3. メールアドレスは必須で、形式が正しくない場合は入力欄の下にエラーを表示します。
4. 電話番号は任意で、ハイフンなしの数字だけを受け付けます。
5. 必須項目がすべて入力されるまで、登録ボタンは無効のままにします。
6. 登録ボタンを押すと、入力内容を保存して一覧画面へ戻ります。
7. 同じメールアドレスの会員がすでにいる場合は、保存せずにエラーを表示します。

## 編集画面

1. 一覧画面で「編集」を押すと、保存済みの内容を入力欄に表示した状態で編集画面を開きます。
2. 入力欄は、新規登録の画面と同じ項目と同じ入力制限を使います。
3. 保存済みの内容を編集する画面では、入力値を変更すると確定ボタンを有効にします。
4. 確定ボタンを押すと、変更した内容を保存して一覧画面へ戻ります。
5. キャンセルボタンを押すと、変更を破棄して一覧画面へ戻ります。
6. 他の管理者が同じ会員を先に更新していた場合は、保存せずに再読み込みを促すメッセージを表示します。

## 削除

1. 確認ダイアログで「削除する」を押すと、会員を論理削除して一覧から除外します。
2. 論理削除した会員は、30日後に物理削除します。
3. 有効な契約が残っている会員は削除できず、ダイアログにその旨を表示します。

## 権限

1. 閲覧権限だけを持つアカウントでは、新規登録・編集・削除のボタンを表示しません。
2. 権限の変更は、次回ログイン時に反映します。

## 操作ログ

1. 登録・編集・削除を行うと、操作した管理者、日時、変更前後の値を操作ログに記録します。
2. 操作ログは1年間保存し、それを過ぎたものは自動で削除します。
