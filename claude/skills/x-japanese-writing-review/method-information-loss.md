# 削除や書き換えで、読み手が文書から得られる情報が減らないかを判定する手順

文を要素に分けて、削除や書き換えの前後で比べます。手順の結果だけで判定します。

## 比べる相手

- 文を削除する場合：その文を削除する根拠にした見出しや文
- 文を書き換える場合：書き換え後の文と、書き換え後の文書のほかの見出しや文

## 手順

1. 削除する文、または書き換える前と後の文を、述語と、述語にかかる要素（主体・対象・条件・時点・手段・理由・結果）に分けて書き出します。説明・指示・理由・実害のような文の働きも書き出します
2. 削る要素を決めます。削除する場合は、削除する文のすべての要素と、その文の働きです。書き換える場合は、書き換える前の文にあって、書き換え後の文にない要素と、その文の働きです。述語の動詞が変わった場合は、態や文末の違いに見えても、変わる前の動詞を削る要素として扱います。次の書き換えは、期限切れと判定する処理を表す「扱う」を削っています
   - 「期限切れとして扱われます」→「期限切れになります」
3. 削る要素を1つずつ、比べる相手と照らし合わせ、「書かれている」「導ける（書かれていないものの、比べる相手だけから導ける）」「導けない」のどれかに決めます
4. 「導ける」と判定した要素は、比べる相手のどの語から導いたかを、指摘や修正の理由に書きます。導いた語を挙げられない場合は、判定を「導けない」に改めます
5. 「導けない」が1つでもあれば、文を元のまま残します。ただし、書き手が指示に従ったことや確認したことだけを述べる要素は、「導けない」と判定しても「導ける」と同じに扱います
6. 書き換え後の文に、ほかの文にある要素を加えた場合は、その要素が書かれていた文を、指摘や修正の理由に書きます
