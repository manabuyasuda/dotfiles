# 記号・記法・文体を決まった形で使うルール

記号・空白・記法・文体の形だけを見て判定します。

## 英数字・記号と日本語の間は詰めて書きます

日本語の文章では、語の間を詰めて書きます。空白の有無が文書内で揃っていないと、読み手は空白の位置を意味の切れ目と受け取ってしまいます。固有名詞やコマンドの引数のように、空白が語の一部である場合は残します。

バッククォートで囲まれたインラインコードの前後も詰めて書きます。

- 誤：「Claude Code を使う」「`true` の場合」
- 正：「Claude Codeを使う」「`true`の場合」

## 水平線は、話題が切り替わる位置にだけ使います

水平線`---`（`hr`要素）は、テーマの意味的な区切りを表します。この用途以外で使うと、実際には続いている内容を、読み手が別の話題として読んでしまいます。線を引いて見た目を整える目的では使いません。

セクションの区切りは見出しで表現します。見出しの直前や直後に置いた水平線は削除します。

## 絵文字を削除します

絵文字は、内容を変えずに見た目だけを強調する装飾です。読み手は、書き手が意図した重要度と関係なく、絵文字を置いた箇所を重要だと受け取ってしまいます。

他者の発言や外部資料からの引用に含まれる絵文字、絵文字そのものを説明する記述、ユーザーが使うと決めた箇所は、そのまま残します。

- 誤：「✅ 差分だけを校正します」
- 正：「差分だけを校正します」

## コードブロックは、機械が解釈する内容と端末に貼り付ける内容にのみ使います

コードブロックを装飾として使うと、機械が解釈する内容と読み手向けの説明を読み手が区別できなくなってしまいます。

対象はソースコード・コマンド・設定ファイル・実行結果です。手順・箇条書き・説明文を整形する目的で挿入されたコードブロックは、リスト・段落・表など通常のMarkdown要素に置き換えます。ただし、ユーザーがそのままコピーして使う出力テンプレートには、コードブロックを使ってかまいません。

## 引用記法は他者の発言や外部資料からの引用にのみ使います

引用記法はMarkdownの`>`とHTMLの`blockquote`要素です。引用記法を装飾として使うと、他者の発言や外部資料と書き手自身の文を読み手が区別できなくなってしまいます。

前提条件・注意書き・補足説明を目立たせる目的で挿入された引用記法は、引用記法を外し、内容に合う形式で書き直します。書き直す形式を指定しないのは、引用記法に入る内容を事前に予測できず、形式を限定すると内容に合わない形式を選んでしまうためです。

## 引用は次の形式で書きます

```
＜英語の引用＞
＜日本語訳＞
＜[引用した情報のタイトル](URL)＞
```

日本語を引用する場合は、日本語訳の行を省略します。

## コロンで終わる文は書き換えます

文の終わりにコロン（半角の`:`と全角の`：`）を付けると、その文は述語で終わらず、読み手は何が述べられたのかを判断できなくなってしまいます。

コロンを削り、その文を述語で終えます。

「誤：」「正：」のようにラベルと内容を区切るコロンは、文の終わりではないため、書き換えません。

- 誤：「次のファイルを校正します：」
- 正：「次のファイルを校正します。」

## 見出しはh1から順に、階層を飛ばさずに使用します

見出しのレベルは文書の階層構造を表すため、階層を飛ばすと、読み手と目次生成ツールの両方が見出しの親子関係を取り違えてしまいます。

他の文書に取り込まれる部分ファイルは、取り込み先の階層に合う見出しから始めます。

## 文末は敬体（です・ます調）で書きます

文体が混在すると、読み手は文体が切り替わった理由を考えることになり、内容に集中できなくなってしまいます。時と場所を選ばずに使える敬体に統一します。

常体を見つけた場合は、修正する前に、どちらに統一するかの方針をユーザーへ提案し、了承を得てから修正します。

- 誤：「〜だ」「〜である」「〜した」「〜する」「〜している」
- 正：「〜です」「〜です」「〜しました」「〜します」「〜しています」

違反例として引用する文と、他者の発言や外部資料からの引用は、原文のまま残します。名詞止めか「こと」止めで揃えた箇条書きの項目は対象外です。

## 話し言葉を書き言葉にします

話し言葉は、相手とやり取りしながら伝えるための言葉です。書き言葉は、文章だけで正確に伝えるための言葉です。文書に話し言葉を使うと、「すごく」がどの程度か、「〜とか」に何が含まれるか、「〜けど」が逆接か前置きかを読み手が文章から判断できず、読み手ごとに受け取り方が分かれてしまいます。

対象は「ちゃんと」「すごく」「〜とか」「〜けど」「〜じゃない」、文頭の「なので」のような話し言葉の語です。他者の発言の引用は、原文のまま残します。

- 誤：「設定ファイルとか環境変数を確認したけど、原因はわからなかったです」
- 正：「設定ファイルと環境変数を確認しました。しかし、原因はわかりませんでした」
- 誤：「なので、プロセスを再起動します」
- 正：「そのため、プロセスを再起動します」

## 補助的な語はかなで書き、漢字の語を続けて書きません

補助的な語まで漢字で書いたり、漢字の語を続けたりすると、読み手は文の要点の語を見分けられなくなってしまいます。

- 漢字で書く語：名詞・代名詞・動詞・形容詞・形容動詞・主な副詞
- かなで書く語：助詞・助動詞・形式名詞（「こと」「とき」「もの」「ところ」）・補助動詞（「〜していく」「〜してください」）・接続詞（「しかし」「ただし」「および」）

「14時」の「時」のように、語の意味を担う漢字は残します。別々の漢字の語は、読点かかなで区切ります。合成語と複合名詞は区切りません。

- 誤：「設定を変更する事」「エラーが出た時は」「確認して下さい」「本日担当者に連絡します」
- 正：「設定を変更すること」「エラーが出たときは」「確認してください」「本日、担当者に連絡します」

## 箇条書きの各項目は、同じ表現形式で書きます

名詞止めの項目が文の項目と混ざると、読み手は、その項目が実行する手順なのか、手順の名前なのかを判断できなくなってしまいます。

表現形式は、述語を含む1つの文、名詞止め、「こと」止めのいずれかです。1つの箇条書きの中では、すべての項目を同じ形式に揃えます。

誤

```markdown
- 設定ファイルを作成します
- サービスの起動
- ログを確認すること
```

正

```markdown
- 設定ファイルを作成します
- サービスを起動します
- ログを確認します
```
