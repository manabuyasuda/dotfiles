# リモートワークの導入について

リモートワークの普及は、働き方に大きな変化をもたらしました。重要なのは、通勤時間の削減による生活の質の向上です。また、オフィスコストの削減という企業側のメリットも見逃せません。このように、リモートワークは労働者と企業の双方にとって恩恵のある働き方だと言えるでしょう。

社内調査によると、導入後に「集中できる時間が増えた」と答えた社員は68%でした。一方で、雑談が減ったことでチームの一体感が下がったという声も上がっています。したがって、週に一度は出社日を設ける運用が望ましいと考えられます。

`config.json`のフラグを`true`にすると、勤怠システムがリモート勤務を自動で記録します。

- 出社日は水曜日
- 会議は原則オンライン
