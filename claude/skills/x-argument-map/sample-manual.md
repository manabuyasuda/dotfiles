# 勤怠システムの運用手順

勤怠システムは、社員の出退勤打刻と残業申請を管理します。管理者は月次で勤怠データを集計し、給与計算システムに連携します。

## 打刻の修正

打刻の修正申請は、原則として翌営業日までに提出します。

## 指示語

打刻の修正申請と残業申請は、それぞれ別の承認フローに乗ります。これを承認します。

管理者権限で実行してください。

## 条件分岐

申請者が管理職の場合は、承認者は事業部長になります。

## 用語

フラッシュキャッシュを有効にすると、応答時間が短縮されます。

## 数量

サーバーの起動には最大3かかります。

## 手順の粒度

打刻の修正手順は次の通りです。

- 打刻の修正申請画面を開く
- 修正対象日を選択し、修正前と修正後の打刻時刻を入力し、修正理由を150文字以内で記入し、承認者を選択して申請ボタンを押下する
- 保存
- 完了通知を確認する
