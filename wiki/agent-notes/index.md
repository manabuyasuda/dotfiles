# Agent Notes Index

エージェントノート（AIエージェントが作業をするときの推奨パターン）の索引です。

## 分類

| 分類 | ディレクトリ | 判定の目安 |
|---|---|---|
| 最初からうまくいった | `worked-first-try/` | エージェントの応答のあとに、ユーザーの修正指示もエージェントの再試行も入らずに次の作業へ進んでいる区間です |
| 試行錯誤でうまくいった | `worked-after-retry/` | ユーザーの指示なしに、エージェントが別の方法に変更して再試行し、最終的に通った区間です。試した順に方法を残します |
| ユーザーの指示でうまくいった | `worked-with-guidance/` | ユーザーの発言を挟んでやり直している区間です。やり直し直前のユーザーの発言を指示の内容として拾います |
| 失敗した | `failed/` | ユーザーが止めた、エージェントが別の方法に変更して再試行しても解決に至らなかった、コマンドが失敗した、の3つを区別します |
| 繰り返し調べている | `recurring-lookups/` | ツール呼び出し（ファイル読み取り・検索・外部参照）の対象別回数から、繰り返し参照している構造や仕様を拾います |
